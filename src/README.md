
# Python Source Code

This folder contains reusable Python scripts for
the Detroit Tigers Pitching Analysis project.

## Planned Modules

- data_collection.py
  Retrieve MLB Statcast pitching data.

- data_cleaning.py
  Clean datasets and handle missing values.

- feature_engineering.py
  Calculate advanced pitching metrics and
  create machine-learning features.

- modeling.py
  Train and evaluate predictive models.

- visualization.py
  Generate reusable charts and visualizations.

## Tools

Python, Pandas, NumPy, Scikit-learn, PyBaseball
